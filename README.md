# Muhammad Hannan website

This website is ready to publish on GitHub Pages for free.

## Publish it

1. Sign in or create an account at https://github.com.
2. Create a new public repository named `muhammad-hannan`.
3. Upload every file in this folder to that repository.
4. In the repository, open **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and the `/ (root)` folder. Save.

Your site will be available at:

`https://YOUR-GITHUB-USERNAME.github.io/muhammad-hannan/`

## Google Search

After the website is live, add its final address in Google Search Console:
https://search.google.com/search-console

Google can then index it. Search results may take several days or weeks to appear.

## Personalize Instagram

Open `script.js`, then put your Instagram username between the quotation marks:

```js
const instagramUsername = "your_username";
```
